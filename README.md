# IIoT Pathfinder – Zero-to-Hero Industrial IoT Learning & Certification Readiness App

An interactive, self-paced learning roadmap and **Certification & Profile Readiness Engine** designed to guide learners from zero prior background to a full-stack **Industrial IoT (IIoT) & Enterprise Integration Engineer**.

## ✨ Key Features

- **20 Structured Modules (~420 Study Hours)** across 8 Phases:
  1. **Foundations**: IIoT Orientation (ISA-95, Purdue Model, OEE, Unified Namespace) & Industrial Networking, Linux CLI, and 4–20 mA Sensor Signals
  2. **Programming**: Core Java 21 & Advanced Concurrent Java for IIoT (Virtual Threads, Eclipse Milo, Apache PLC4X, HiveMQ MQTT Client)
  3. **Mainframe Enterprise Integration**: IBM z/OS Fundamentals, JCL Batch Pipelines, Enterprise PL/I Programming, and Mainframe Integration (CICS, Db2, IBM MQ, z/OS Connect)
  4. **Operational Technology (OT)**: PLCs & SCADA (IEC 61131-3, PackML, ISA-18.2), Industrial Protocols & Sensor Simulation (Modbus TCP/RTU, PROFINET, EtherNet/IP, S7), OPC UA, and MQTT with Sparkplug B (ISO/IEC 20237)
  5. **Edge Computing**: Edge Runtimes & Industrial Gateways (Node-RED, EdgeX Foundry, Eclipse Kura) and Lightweight Containers & Orchestration (Docker, Podman, K3s, GitOps, SBOMs)
  6. **Data Platform**: Time-Series Ingestion & Storage (Telegraf, InfluxDB, TimescaleDB, Grafana) and Enterprise Message Broker Fabric (HiveMQ/EMQX Clustering & Apache Kafka)
  7. **Cloud & Intelligence**: Cloud Integration & Digital Twins (AWS IoT, Azure IoT, Asset Administration Shell / Eclipse BaSyx), Industrial Cybersecurity (ISA/IEC 62443, NIS2, CRA), and Industrial AI & Predictive Maintenance (FFT, RUL, ONNX Runtime)
  8. **Career & Capstone**: End-to-End *"Smart Factory in a Box"* Capstone & Professional Profile Launch

- **🌱 Zero-Prior-Experience Primers**:
  - Plain-English mental models & real-world analogies for every topic
  - Jargon Decoder glossary tables
  - Step-by-step beginner walkthroughs and common pitfall guides
- **🛠 Interactive Lab Checklists & Career Artifact Builder**:
  - Checkable hands-on lab milestones persisted in browser storage
  - Unlocked competency tags, GitHub portfolio deliverables, copy-ready quantified CV/Resume bullets, and model technical interview Q&As
- **🏅 Post-Quiz Certification & Profile Fitness Engine**:
  - **161 Checkpoint Quiz Questions** (80% pass mark to unlock the next module)
  - Automatically evaluates your completed modules and mastery scores against **21 official industry certifications and free verifiable badges** (IBM Z Xplore, Oracle Java, IBM MQ, Inductive Automation Ignition, OPC Foundation, HiveMQ Sparkplug B, Linux Foundation/CNCF, InfluxDB University, Confluent Kafka, AWS/Azure IoT, ISA/IEC 62443)

## 🚀 Quick Start

### Option 1: Run with Node.js Server
```bash
node server.js
```
Then open **http://localhost:8080** in your browser.

### Option 2: Open Directly
Open `index.html` directly in any modern web browser.
